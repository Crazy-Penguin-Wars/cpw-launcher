This is the repository for the Crazy Penguin Wars launcher, an Electron app with an embedded version of Adobe Flash Player. Only used for the demo and map editor versions of the game, for the multiplayer client, see [the cpw-client repository](https://github.com/Crazy-Penguin-Wars/cpw-client).

## Credits
This repository is forked from the team at NewCP: https://github.com/New-Club-Penguin/NewCP-App. Huge thanks to them!

## Setup

- Please make sure you have [nodejs](https://nodejs.org/en/download/) and [yarn](https://classic.yarnpkg.com/lang/en/docs/install) installed. 
- Clone this repository.
- Install node dependencies using the command `yarn install`.

## Running
To run the NewCP client, use the following command:
```
yarn start
```
